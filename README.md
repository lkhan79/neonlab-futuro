# ⚡ NeonLab Futuro — Progetto finale

Un sito web futuristico in stile **neon/cyberpunk**, sviluppato come progetto pratico in 15 lezioni di HTML, CSS e JavaScript.

## 🌍 Sito online

[Visita NeonLab Futuro](https://lkhan79.github.io/neonlab-futuro/)

## ✨ Funzionalità

- Design responsive con sfondo a gradienti, effetti vetro e colori neon.
- Navigazione mobile, collegamento di accessibilità e animazioni rispettose delle preferenze di movimento ridotto.
- Cambio tema, contatore energia e schede tecnologiche interattive.
- Galleria con anteprime ingrandite e chiusura da tastiera.
- Sezione portfolio che racconta il percorso di sviluppo.
- Modulo che prepara una bozza email nel programma di posta (senza invio automatico).
- Pulsante per tornare in cima alla pagina e anno aggiornato automaticamente.

## 🧰 Tecnologie

HTML5, CSS3, JavaScript e grafica SVG. La versione pubblica è statica e non richiede pacchetti esterni.

Durante il corso è stato sviluppato anche un **backend Node.js locale**, conservato separatamente dalle versioni pubbliche. Questo repository **non** contiene il server o gli archivi privati dei messaggi.

## ▶️ Come provarlo

Scarica i file e apri `index.html` nel browser.

Per pubblicare modifiche su GitHub Pages, carica i file aggiornati nella radice del repository, conservando la cartella `assets`.

## 📬 Contatti

Per usare la bozza email, configura `EMAIL_DESTINATARIO` in `script.js` con un indirizzo dedicato di tua proprietà. Tieni presente che sarà visibile nel codice pubblico e che i visitatori dovranno inviare l'email dal loro programma di posta.

## 📖 Percorso di formazione

Progetto finale di un corso pratico di 15 lezioni: dalle basi di HTML alla pubblicazione di un sito statico, con introduzione a Node.js e alle protezioni di base.
